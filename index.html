KR Keyboard

KR Keyboard အက်ပ်ကို အောက်ပါနည်းလမ်း တစ်ခုခုနဲ့ ဒေါင်းလုဒ်လုပ်ပြီး ဖုန်းမှာ သုံးနိုင်ပါပြီ။

Google Play မှ ရယူရန်Play Store မှ တိုက်ရိုက်ထည့်သွင်းပါ APK ဖိုင် ဒေါင်းလုဒ်လုပ်ရန်Play Store မသုံးနိုင်ရင် ဒီနည်းကို သုံးပါ

APK ဖိုင်ကို ထည့်သွင်းနည်း

  1. APK ဖိုင်ကို ဒေါင်းလုဒ်လုပ်ပါ။
  2. ဖုန်း Settings ထဲမှာ Install unknown apps ကို ခွင့်ပြုပါ။
  3. ဒေါင်းလုဒ်ရထားတဲ့ ဖိုင်ကိုဖွင့်ပြီး Install ကို နှိပ်ပါ။
  4. Settings ထဲက Keyboard မှာ KR Keyboard ကို ဖွင့်ပြီး ရွေးပါ။
